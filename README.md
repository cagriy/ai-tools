# ai-tools

A Claude Code plugin marketplace.

## Usage

```
/plugin marketplace add cagriy/ai-tools
/plugin install dev-skills@ai-tools
/plugin install cc@ai-tools
```

## Plugins

| Plugin | Description |
|---|---|
| [dev-skills](https://github.com/cagriy/dev-skills) | TDD-driven feature workflow: design, plan, and implement features end-to-end. Slash commands are namespaced `/dev:` (e.g. `/dev:feature-design`). |
| [cc](https://github.com/cagriy/cc-plugin) | Session-scoped `/cc-model` and `/cc-effort` that keep the saved default, and `/cc-clear` that runs a follow-up action after clearing. Slash commands are namespaced `/cc:` (e.g. `/cc:cc-model sonnet`). |
